A single sentence of horror for the [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488) bounty on make.fun.

The program (`main.ts`, Node 22) writes exactly one sentence — under 200 characters — to `/output/entry.txt`. The line frightens by what it withholds: a familiar emergency call, an address spoken back by a voice that should not be on the line, and a final detail that makes the whole recording impossible. No setup, no second sentence, no gore — one breath, one chill.

Run it with:

```sh
node main.ts
```
